# 💌 צ'אט פרטי ומוצפן

שרת שרץ אצלך במחשב + אתר ב-GitHub Pages. ההודעות מוצפנות בדפדפן (AES-256-GCM) לפני שהן יוצאות,
השרת שומר רק טקסט מוצפן. הסיסמה לא נשלחת לשרת - רק טוקן נגזר ממנה.

## התקנה (פעם אחת)

1. התקן Node.js (nodejs.org) ו-git.
2. התקן cloudflared: `winget install Cloudflare.cloudflared`
3. בתיקייה הזו:
   ```
   npm install
   copy config.example.json config.json
   ```
4. ערוך `config.json`: סיסמה משותפת ארוכה, ומפתח GIPHY חינמי מ-developers.giphy.com (Create an App > API).

## העלאה ל-GitHub Pages

ה-repo כבר קיים ב-GitHub, ויש workflow (`.github/workflows/pages.yml`) שמפרסם את התיקייה `docs/` בכל push.
אם האתר לא עלה: Settings > Pages > Source: **GitHub Actions**.

כדי לעבוד מהמחשב:
```
git clone https://github.com/<USER>/love-chat.git
cd love-chat
npm install
copy config.example.json config.json
```

הקישור: `https://<USER>.github.io/love-chat/` - זה הקישור שנותנים לה.

## הפעלה

הרץ `start.bat` (ב-Mac/Linux: `./start.sh`, או `npm start`). הסקריפט מרים שרת + טונל, מעדכן את כתובת השרת ב-`docs/config.js` ועושה push לבד.
אחרי הפעלה צריך כדקה עד שהאתר מתעדכן.

להפעלה אוטומטית כשהמחשב עולה: `Win+R` > `shell:startup` > שים שם קיצור ל-`start.bat`.

## פרטיות - מה כן ומה לא

- ההודעות, התמונות, ההודעות הקוליות, השמות והסטטוסים מוצפנים. מי שיש לו את הקישור בלי הסיסמה רואה רק מסך כניסה.
- `noindex` + `robots.txt`: גוגל לא ידרג את האתר. הקישור עצמו חשוב לא לפרסם.
- GitHub Pages הוא ציבורי מטבעו (גם ב-repo פרטי, אלא אם יש Enterprise). לכן ההגנה היא הסיסמה וההצפנה, לא הסתרת הכתובת.
- כשהמחשב כבוד, הצ'אט לא זמין. היסטוריה נשמרת ב-`data/messages.json`.
- הודעות וסטטוסים ישנים נמחקים אוטומטית (כל שעה) מהשרת ומהדיסק, וגם מהמסך שלה בלייב. ברירת מחדל: 3 ימים. לשינוי: `retentionDays` ב-`config.json`.
- לשונית "ציר זמן": כל הסטטוסים שלך בסדר כרונולוגי, עם כמה זמן נמשך כל אחד, ומתעדכנת בלייב.
- הסיסמה עצמה לא נשמרת בטלפון - רק המפתח הנגזר ממנה. כפתור 🚪 מוחק אותו מהמכשיר.
- לשינוי סיסמה: עדכן `config.json` ואתחל. הודעות ישנות יהפכו לבלתי קריאות.

## 🏠 מצלמת בית - שידור חי 24/7

כדי שתוכל/י לראות מה קורה בבית בלי לדאוג. מוצפן מקצה לקצה כמו השיחות.

**להפעלה במחשב הבית (רץ כל הזמן):**
1. במחשב שעליו רץ השרת, פתח ב-Chrome: `http://localhost:3000/?cam=1` והתחבר פעם אחת (שם + סיסמה), אשר גישה למצלמה.
2. מעכשיו הדף מתחיל לשדר לבד בכל פעם שהוא נפתח. כדי שזה יעלה אוטומטית עם המחשב:
   `Win+R` > `shell:startup` > קיצור דרך ל-`chrome.exe --new-window http://localhost:3000/?cam=1`
3. בהגדרות החשמל של Windows: לא להכניס את המחשב לשינה (המסך יכול לכבות).

אפשר גם לשדר מטלפון ישן: ⋯ > "🔴 שדר מהמכשיר הזה". המסך נשאר דולק כל עוד השידור פעיל.

**לצפייה:** כפתור 🏠 בראש הצ'אט (נקודה אדומה מהבהבת = יש שידור חי). בצפייה: 🔊 קול, ⏺️ הקלטה
(נשמרת כקובץ אצל מי שצופה בלבד), 📸 צילום מסך.

**שקיפות ובטיחות - בכוונה:**
- את השידור אפשר להפעיל **רק מהמכשיר שמצלם**, אף פעם לא מרחוק.
- במסך המשדר תמיד מופיע **LIVE** אדום ו**מי צופה כרגע** ("👀 צופים כרגע: ...").
- המיקרופון כבוי כברירת מחדל ונדלק רק מהמכשיר המשדר.
- הווידאו עובר ישירות למכשיר הצופה ולא נשמר בשרת. בלי הסיסמה אי אפשר לצפות.
- אם גרים איתך אנשים נוספים - כדאי שיידעו שיש מצלמה פעילה בבית.

אם המצלמה מתנתקת (USB / שינה) - הדף מנסה להחזיר אותה כל 10 שניות, והצופים מתחברים מחדש לבד.

## שיחות וידאו וקול 📹📞

כפתורי 📞 (קולית) ו-📹 (וידאו) בראש הצ'אט. בשיחה: השתקה, כיבוי מצלמה, החלפת מצלמה קדמית/אחורית, ניתוק.
השיחה נרשמת בצ'אט (משך / שיחה שלא נענתה).

**הצפנה מקצה לקצה:** הווידאו והקול עוברים ישירות בין שני המכשירים (WebRTC) ומוצפנים ב-DTLS-SRTP.
ההודעות שמקימות את השיחה (כולל טביעות האצבע של מפתחות ההצפנה) מוצפנות ב-AES-GCM עם מפתח הצ'אט
לפני שהן עוברות דרך השרת - כך שהשרת לא יכול לראות אותן, לשנות אותן או להתחזות לאחד הצדדים. השרת לא שומר אותן.

**רשתות קשוחות:** ברוב המקרים החיבור הישיר עובד. אם שיחה נכשלת ("החיבור נכשל") - בדרך כלל ברשת סלולרית/ארגונית
עם NAT קשוח - אפשר להוסיף שרת TURN ב-`config.json` (למשל Cloudflare Calls TURN או metered.ca, יש חינמיים).
המדיה עדיין מוצפנת מקצה לקצה; שרת ה-TURN רק מעביר אותה ולא יכול לפענח:
```json
"iceServers": [
  { "urls": "stun:stun.cloudflare.com:3478" },
  { "urls": "turn:turn.example.com:3478", "username": "...", "credential": "..." }
]
```
שים לב: פרטי ה-TURN נכנסים ל-`docs/config.js` שהוא ציבורי - השתמש בפרטים שמותר שיהיו גלויים או מוגבלים בזמן.
