# 💌 צ'אט פרטי ומוצפן

שרת שרץ אצלך במחשב + אתר ב-GitHub Pages. ההודעות מוצפנות בדפדפן (AES-256-GCM) לפני שהן יוצאות,
השרת שומר רק טקסט מוצפן. הסיסמה לא נשלחת לשרת - רק טוקן נגזר ממנה.

## התקנה (פעם אחת)

1. התקן Node.js (nodejs.org) ו-git.
2. התקן cloudflared: `winget install Cloudflare.cloudflared`
3. בתיקייה הזו:
   ```
   npm install
   copy config.example.json config.json
   ```
4. ערוך `config.json`: סיסמה משותפת ארוכה, ומפתח GIPHY חינמי מ-developers.giphy.com (Create an App > API).

## העלאה ל-GitHub Pages

ה-repo כבר קיים ב-GitHub, ויש workflow (`.github/workflows/pages.yml`) שמפרסם את התיקייה `docs/` בכל push.
אם האתר לא עלה: Settings > Pages > Source: **GitHub Actions**.

כדי לעבוד מהמחשב:
```
git clone https://github.com/<USER>/love-chat.git
cd love-chat
npm install
copy config.example.json config.json
```

הקישור: `https://<USER>.github.io/love-chat/` - זה הקישור שנותנים לה.

## הפעלה

הרץ `start.bat` (ב-Mac/Linux: `./start.sh`, או `npm start`). הסקריפט מרים שרת + טונל, מעדכן את כתובת השרת ב-`docs/config.js` ועושה push לבד.
אחרי הפעלה צריך כדקה עד שהאתר מתעדכן.

להפעלה אוטומטית כשהמחשב עולה: `Win+R` > `shell:startup` > שים שם קיצור ל-`start.bat`.

## פרטיות - מה כן ומה לא

- ההודעות, השמות והסטטוסים מוצפנים. מי שיש לו את הקישור בלי הסיסמה רואה רק מסך כניסה.
- `noindex` + `robots.txt`: גוגל לא ידרג את האתר. הקישור עצמו חשוב לא לפרסם.
- GitHub Pages הוא ציבורי מטבעו (גם ב-repo פרטי, אלא אם יש Enterprise). לכן ההגנה היא הסיסמה וההצפנה, לא הסתרת הכתובת.
- כשהמחשב כבוד, הצ'אט לא זמין. היסטוריה נשמרת ב-`data/messages.json`.
- הודעות וסטטוסים ישנים נמחקים אוטומטית (כל שעה) מהשרת ומהדיסק, וגם מהמסך שלה בלייב. ברירת מחדל: 3 ימים. לשינוי: `retentionDays` ב-`config.json`.
- לשונית "ציר זמן": כל הסטטוסים שלך בסדר כרונולוגי, עם כמה זמן נמשך כל אחד, ומתעדכנת בלייב.
- הסיסמה עצמה לא נשמרת בטלפון - רק המפתח הנגזר ממנה. כפתור 🚪 מוחק אותו מהמכשיר.
- לשינוי סיסמה: עדכן `config.json` ואתחל. הודעות ישנות יהפכו לבלתי קריאות.

## מה חדש בגרסה 1.1

- **חיבור מחדש אוטומטי לכתובת חדשה**: כתובת הטונל משתנה בכל הפעלה. דף פתוח טוען מחדש את `config.js` כשהחיבור נופל ועובר לכתובת החדשה לבד - בלי לרענן.
- חיבור מיידי כשחוזרים לאפליקציה בטלפון, פס "מתחבר מחדש..." כשאין חיבור, ו-keepalive שמונע מהטונל לנתק חיבור שקט.
- התראות דפדפן (🔔) על הודעה חדשה כשהדף ברקע.
- כפתור יציאה (🚪). הסיסמה כבר לא נשמרת ב-localStorage, רק מפתח נגזר.
- שרת: שמירה אטומית לדיסק (בלי קובץ פגום בקריסה), שמירה ביציאה, heartbeat שמנקה חיבורים מתים (נקודה ירוקה אמינה), הגבלת קצב הודעות, בדיקת תקינות קלט, ניקוי רשימת חסימות.
- `run.js`: אם ה-push נכשל - `pull --rebase` וניסיון נוסף; המתנה הולכת וגדלה כשהטונל נופל שוב ושוב.
- השרת מגיש גם את האתר עצמו: `http://localhost:3000` עובד לבדיקה מקומית, וכתובת הטונל עובדת כגיבוי אם GitHub Pages לא זמין.
- `npm test` - בדיקות לשרת, ו-CI ב-GitHub Actions.
